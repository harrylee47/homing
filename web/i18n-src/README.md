# 词表的源

`web/i18n-en.js` 是**生成物**，别手改。改这里，然后：

```bash
node scripts/build-i18n.mjs web/i18n-src
```

- `app-*.json` / `welcome-*.json` / `misc.json` / `api.json` —— 按文件与行段切开的分片。
- `overrides.json` —— **人工覆盖层，最后应用、一律盖过分片。**

改译文优先改 `overrides.json`，不要改分片：分片是机器按源码段产出的，
下次重新生成就回去了；覆盖层才是持久的。

## key 长什么样

引擎（`web/i18n.js`）只做**整串精确匹配**：把运行时那段文本 trim 之后查表。
不做片段替换——控制台里显示的是短信正文，片段替换会把真实短信弄脏。

查表发生在**标签之间的每一段文本**上，不是整个模板字符串上。源码里写

```js
`<b>验证码</b> 高优先级、自动提取`
```

运行时会被拆成两段去查：`验证码` 和 `高优先级、自动提取`。所以要分别给两条。

含 `${...}` 插值的串精确匹配不上，用 `rules` 里的正则，**必须 `^` 开头 `$` 结尾**
（不锚定会误伤用户数据，build 脚本会直接拒绝）。
